## Project Motion Languages

- NJU Match, connect: relationship nodes reorganize around a shared line.
- Fimel, build: modules separate, compress, and rebuild as blocks.
- Wide Research, structure: noisy information streams converge into readable paths.
- Enzyme Explorer, react: particles attract, repel, combine, and become film structure.

## Mobile Script

- Native vertical reading order.
- No persistent shared photograph layer.
- Short section reveals instead of long chained pins.
- Tap opens the same project stories used on desktop.
- Drag remains available inside the bounded Playground stage.
- The last page stays readable and does not force the closing-cover sequence.
